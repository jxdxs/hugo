航班中转是否要办过境签证？2025—2026各国政策完整说明

中转要不要办过境签证，是出境游里最容易翻车的问题之一。很多人以为"不出机场就不需要签证"，这个说法只对了一部分。不同国家的规定天差地别，有的免签24小时，有的不出中转区也需要签证。

下面按四个维度给你说清楚。

一、基本原则：先判断你属于哪种情况

情况是否需要过境签证
联程机票（同一个票号），全程国际中转区中转，不出中转区，不入境大部分国家免签（但有例外，见下文）
非联程机票，需要入境取行李→重新托运基本都需要过境签或入境签
换机场中转（如从成田T1到羽田）必须入境，需要签证
过夜中转，需要入境住酒店需要过境签或免签入境资格
中转时间超过24/48/72小时各国有不同规定，多数需要签证

简单判断：

  • 联程机票 + 不出中转区 + 中转时间短 → 多数国家不需要签证
  • 非联程 + 需要拿行李 + 跨航站楼/跨机场 + 过夜 → 基本都需要办手续

二、重点国家和地区的具体规定

🇨🇳 中国（针对外国人经中国中转）

  • 24小时过境免签：全部对外开放口岸，所有国家人员，持联程机票 → 免签（限口岸限定区域内，不出关）
  • 144小时过境免签（6天）：54国公民，可从指定口岸入境并在限定区域内活动，需提前申报
  • 2025—2026年还扩大了单方面免签国家范围（法国、德国、意大利、西班牙等30多国），这些国家公民来华≤30天免签

🇺🇸 美国——⚠️ 特别严格

  • 无论是否出中转区，都需要签证
  • 持中国护照者，转机必须申请 C类过境签证（或B1/B2旅游签证）
  • 如果是免签证计划（VWP）国家的公民，需通过ESTA授权
  • 美国没有"不出中转区就免签"这回事

🇬🇧 英国——DATV 要求严格

  • 许多国家公民经英国转机（即使不出机场中转区）也需要 直接航空中转签证（DATV）
  • 持中国护照者：如果转机时间短、不入境、有美国/加拿大/澳大利亚/新西兰/申根/爱尔兰签证且使用过，部分情况可免签过境——但建议出发前查好
  • 如果中转时间超过24小时，几乎都必须办DATV

🇪🇺 申根区（26个欧洲国家）

  • 分为两种：
    1. 机场中转区过境：部分国家公民需要"机场过境签证"（A类签证）
    2. 入境中转：需要短期申根签证
  • 持中国护照者：
    • 如果持有有效申根签证、或特定国家（美/加/日/韩等）签证，部分申根国允许机场中转区免签过境（如法国、德国、荷兰）
    • 但每个申根国规定不同，比如西班牙2025年起对特定国家公民收紧了过境签证要求
  • 另外，ETIAS（欧洲旅行信息和授权系统）预计2026年底上线，届时免签国家公民进入申根区（包括中转）也需要事先电子授权

🇯🇵 日本

  • 持中国护照者：一般情况需要过境签证
  • 例外情况：
    • 持有美国、加拿大、澳大利亚、新西兰、申根签证或永久居留卡 → 可申请"过境免签"（在机场现场办理「寄港地上陸許可」，原则上72小时内）
    • 不离开中转区的纯转机（不出关），实际上不需要日本签证

🇰🇷 韩国

  • 持中国护照者：
    • 持有美国、加拿大、澳大利亚、新西兰、欧洲30国签证（含永居） 经韩国转机 → 可免签入境停留30天（往返均可）
    • 前往美国/加拿大/澳大利亚/新西兰经韩国转机 → 可免签入境30天
    • 从美国/加拿大/澳大利亚/新西兰经韩国转机返回中国 → 可免签入境30天
    • 仅限仁川国际机场（金浦等机场有限制）

🇸🇬 新加坡

  • 持中国护照者：
    • 联程机票 + 不出中转区（樟宜机场）→ 免签
    • 如果需要入境（如过夜），持有效美国/加拿大/英国/澳大利亚/新西兰/申根/日本等多国签证 → 可申请96小时VFTF免签过境
    • 2024年起中国新加坡互免签证，实际上已无需再担心过境问题

🇲🇾 马来西亚

  • 持中国护照者：
    • 联程机票 + 不出机场（吉隆坡KLIA/KLIA2有专门的转机通道）→ 免签
    • 非联程或需要入境 → 可申请120小时过境免签（要求持有前往第三国的机票，部分口岸支持）

🇦🇪 阿联酋（迪拜）

  • 持中国护照者：互免签证，直接免签入境30天
  • 所以中转迪拜完全不需要操心过境签证的问题

🇹🇭 泰国

  • 持中国护照者：免签入境60天
  • 中转完全没问题

🇭🇰 / 🇲🇴 中国香港 / 中国澳门

  • 持中国护照者：过境前往第三国 → 可免签停留7天（无需港澳通行证，出示护照+联程机票）
  • 注意：从大陆直接去香港转机，凭护照+机票可直接入境香港，不需要港澳通行证

🇨🇦 加拿大

  • 持中国护照者：
    • 经加拿大转机前往美国 → 符合条件者可免签过境（CBSA的"中国过境计划"CTP）
    • 经加拿大转机前往其他第三国 → 需要过境签证或旅游签证
    • 有条件免签要求：持有效美国签证、从指定亚洲机场出发、乘坐指定航空公司、在温哥华或多伦多转机

🇦🇺 澳大利亚

  • 持中国护照者：无论是否出中转区，都必须持有澳大利亚签证（或过境签证Subclass 771）
  • 没有"不出机场就免签"的说法

四、几条实操铁律

  1. 先确认护照免签国：如果你的护照对中转国是免签的，那中转根本不是问题
  2. 联程机票最好：一个票号 = 航空公司帮你负责行李直挂、转机指引，大部分中转区免签适用于此
  3. 非联程机票风险高：需要入境取行李 → 需要签证
  4. 中转时间别太紧也别太松：2—4小时是安全窗口，时间太长（如过夜）就要考虑入境问题
  5. 有些国家按"国籍"而非"护照"区分：比如申根A类过境签主要针对阿富汗、叙利亚、伊拉克等国公民，不按护照颜色一刀切
  6. 出发前用IATA Timatic核实：绝大多数航空公司用这个系统判断你能不能上飞机，比网上攻略靠谱。可访问 IATA Travel Centre 或让航司帮你查
  7. 不要相信"大家说不用"：航司柜台值机时如果系统显示你目的地/中转地需要签证，你连登机牌都拿不到

五、总结一个思维框架

这趟航班过境要不要签证？
│
├─ 我的护照对中转国是否免签？
│   ├─ 是 → 随便转，甚至能入境玩
│   └─ 否 → 继续判断
│
├─ 联程机票，不出中转区，时间短？
│   ├─ 是 → 大部分国家免签（美国、澳大利亚、加拿大除外）
│   └─ 否 → 基本需要过境签证
│
└─ 还是不确定？
    └─ 用 IATA Timatic 查 / 问航司客服

免责声明：各国签证政策随时可能调整，出行前请务必以官方渠道（移民局/使馆/航司）的最新信息为准。本文信息仅供参考，不作为法律依据。
